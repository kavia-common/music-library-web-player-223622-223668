# Music Library Web Player

This workspace includes:
- frontend_music_player (React): Minimalist Ocean Professional UI for browsing and playing tracks
- backend (Django): API for listing tracks and streaming audio

Quick start:
- Backend: see backend/README.md, run on port 3001
- Frontend: see frontend_music_player/README.md, run on port 3000

Ensure CORS allows 3000 in backend.
